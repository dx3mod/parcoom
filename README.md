# parcoom

Super Fast and Lightweight Monadic Parser Combinator library in idiomatic OCaml. No dependencies (almost).

## Quick Start

```console
$ git clone https://github.com/dx3mod/parcoom-idiomatic.git
$ dune build
$ dune test
$ dune utop
```
